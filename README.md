# Open Campus

A free, open source university across every major degree, written as data with a thin static site on top, and re-run on every Claude model release. Live at https://campus.seansooch.dev.

- [SPEC.md](SPEC.md): the design (draft v0.2)
- [CATALOG.md](CATALOG.md): research behind the catalog, per college and program
- [ARCHITECTURE.md](ARCHITECTURE.md): what exists in the repository today
- [DECISIONS.md](DECISIONS.md): decisions, append-only

Not accredited. Grants no degrees or credit. Not affiliated with any testing or licensing body.
